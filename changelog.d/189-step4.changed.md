- **Backend and scripts no longer name one person's hosts**: the User-Agent of the importer's store lookup, the artist image fetcher, MusicBrainz, the popular tracks client and the artist evidence client is built by `services/common/user_agent.py` from the new `project_url` setting (environment `PROJECT_URL`, group About). It is empty by default, and then the User-Agent carries no address. `PHPMYADMIN_URL` defaults to empty. `tools/` and `scripts/` take hosts from the environment (`tools/env_required.py`: exit 2 and the missing names) instead of a built-in LAN address. `scripts/ci/prod-ssh-setup.sh` needs the CI/CD variable `PROD_REMOTE_HOST`, and `release:check-secrets` checks it. `DOCKER_USER` defaults to `muma`, the runner janitor reads its release image prefix from it, and `renovate.sh` takes its endpoint and project from the CI environment. Production deploys behave the same while `PROD_REMOTE_HOST` and `DOCKER_USER` are set. Issue #189, step 4.
