- **The server address and the Google client id are build settings now.** `StaticServers.SERVER_URL`,
  the client id of "Sign in with Google" and an optional own host for the MuMa API come from the
  Gradle properties `muma.serverUrl`, `muma.googleClientId` and `muma.apiUrl`, in CI from the
  variables `MUMA_SERVER_URL`, `MUMA_GOOGLE_CLIENT_ID` and `MUMA_API_URL`. A build without them uses
  `https://music.example.org` and hides the Google button. A release build stops when the first two are missing, in
  Gradle and in CI. A server on the same domain as the configured one still gets the own API host. The app behaves the same for a build that sets them (#189).
