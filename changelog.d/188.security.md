- **Twee hulpscripts hadden het productiewachtwoord van de database in de code staan.**
  `scripts/cleanup_redundant_indices.py` en `tools/quick_inspect.py` lezen host, gebruiker en
  wachtwoord nu uit `DB_HOST`, `DB_USER` en `DB_PASS` (optioneel `DB_PORT`, `DB_NAME`) en stoppen
  met een melding die de ontbrekende variabelen noemt. Een test in `tests/ci/` laat de build falen
  zodra een getrackt Python-bestand een tekstwaarde als wachtwoord aan `connect()` geeft. Het
  wachtwoord zelf moet nog gedraaid worden (#188).
