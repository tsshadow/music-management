- **A guided script rotates every credential that was ever committed.**
  `scripts/prod/person/rotate-leaked-credentials.sh` reads the leaked values from git history
  (the database password of #188 and the `.env` and `.server-env.json` values in
  `.gitleaksignore`), checks by hash which ones production still uses, and replaces those. It
  backs up every GitLab variable and file it changes, changes the database user, recreates only
  the containers that held an old value, and checks that the old value is refused and `/health`
  reports `database: ok`. `--dry-run` only reads. `--auto-fix` asks nothing. Refs #188, #189.
