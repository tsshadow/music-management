- The scanner now removes the library entry of a file that is gone from disk. A moved or deleted release folder used to leave its rows behind for good: 8,372 of 354,222 media rows on production on 2026-10-03. The track stays, with its ratings and listens. A track whose file was moved and retagged takes its history to the track the file became. Nothing is removed when the share is not mounted, a library folder is empty, or more than 10% of the files look gone. The setting `scanner_drop_vanished_media` on the Beheer config page switches it off (#170, bug report 149).
